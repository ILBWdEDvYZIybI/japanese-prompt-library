# japanese-prompt-library

日常で使いやすい日本語AIプロンプトをまとめたライブラリです。  
ChatGPTなどの生成AIを使うときに、文章作成、要約、学習、仕事効率化などで再利用できるプロンプトを整理しています。

## 特徴

- 日本語でそのまま使えるプロンプト集
- 用途別にカテゴリ分け
- 初心者でも使いやすいシンプルな構成
- CLIツールでプロンプトを検索可能

## 使い方

このリポジトリの `prompts.json` から、目的に合ったプロンプトをコピーして使います。

例：

```text
あなたは文章改善の専門家です。
以下の文章を、自然で読みやすい日本語に修正してください。

# 文章
{ここに文章を入力}
````

## CLIツールの使い方

Pythonが使える環境では、以下のコマンドでプロンプトを検索できます。

```bash
python cli.py
```

キーワード検索：

```bash
python cli.py --search 要約
```

カテゴリ指定：

```bash
python cli.py --category writing
```

## 収録カテゴリ

* writing: 文章作成・文章改善
* summary: 要約
* learning: 学習サポート
* business: 仕事効率化
* coding: プログラミング補助
